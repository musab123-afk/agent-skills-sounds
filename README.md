# agent-skills-sounds

The sound effects used by the launch-video and readme-to-video agent skills: 10 kinds of hit (click, key, pop, soft, swoosh, whoosh, thud, tick, rise, done), three versions of each, synthesised in-house by Shotstack. `sfx/manifest.json` lists each file's length and the time of its peak, so a sound can be placed with its peak on the beat.

They are hosted here so Shotstack renders can fetch them from a public link, through jsDelivr:

```
https://cdn.jsdelivr.net/gh/musab123-afk/agent-skills-sounds@v1/sfx/<file>.mp3
```

Free to use in any video made with these skills.
